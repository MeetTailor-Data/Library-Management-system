PERSON 4 feature/circulation-database
Circulation, Fines & Database
ACID Engine, Business Logic & Sync
📂 Assigned Project Files
database.sql library.db (SQLite) backend/circulation.php backend/db.php & config.php assets/js/slms-store.js server.js (circ routes)
⚡ Core Responsibilities
  • Relational SQL Schema: 4 core tables (users, books, issued_books, messages).
  • Atomic Stock Management: Atomically decrements available copies on issue and restores on return.
  • Borrow Limits: Enforcing strict max 3 books per student & preventing duplicate checkouts.
  • Due Date Engine: Automatically calculates 14-day loan return date upon issue timestamp.
  • Overdue Fine Engine: Computes late penalty fines dynamically at ₹5 per day overdue.
  • Reactive State Sync: 3.5s background polling and multi-tab sync via slms_data_changed.
🎤 Viva / Demo Speaking Topic
"Relational database design, ACID transaction integrity during book issue/return, and dynamic fine calculation algorithm."
