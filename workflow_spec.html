📌 1. Executive Summary & Dual-Engine Architecture

The Smart Library Management System (SLMS) is a production-ready web application engineered to automate the complete lifecycle of library administration: book cataloging, member authentication, borrowing circulation, automated overdue fines calculation, and administrative inventory oversight.

The system utilizes a Dual-Engine Model offering maximum deployment flexibility:

  • Engine A (Primary Local Engine — Node.js + SQLite): Runs natively via server.js on port 3000. It requires zero third-party NPM packages, utilizing Node's built-in node:sqlite module to provide ACID-compliant relational SQL queries in library.db.
  • Engine B (Web / Production Engine — PHP 8.x + PDO): Modular RESTful controllers under backend/ supporting enterprise MySQL/MariaDB with automatic seamless fallback to a local SQLite database (library.sqlite).
  • Reactive State Engine (assets/js/slms-store.js): Polls server endpoints every 3.5 seconds, bridges local browser storage cache with the SQL database, and broadcasts updates via window events (slms_data_changed).

Pages/aboutus.html About Library: Library vision, mission statement, core organizational values, and operational milestones.

Pages/blog.html News & Updates Feed: Library announcements, new book arrivals, events, and reading community articles.

2.3 Backend Engine (backend/)

Backend File Responsibilities & Controller Logic
backend/config.php Database configuration matrix. Reads environment variables (DB_HOST, DB_NAME, etc.) or sets local defaults. Configures SQLite fallback path.
backend/db.php PDO connection factory, schema migrator, automated table creator, fine computation engine (calculate_overdue_fine() at ₹5/day), session validators, and JSON response helper.
backend/auth.php Handles action=login, action=signup, action=logout, and action=get_user. Validates unique IDs, hashes passwords, and starts PHP sessions.
backend/books.php Inventory controller: action=list (with search/category filters), action=get, action=add (validating ISBN uniqueness), action=edit, and action=delete.
backend/circulation.php Circulation controller: action=issue (validating student existence, max 3-book limit, duplicate issue check, and decrementing stock), action=return (restores stock), action=student_borrows, and action=list_all.
backend/contact.php Inquiries controller: action=submit (saves user message to SQL) and action=list (loads all messages for the admin panel).

2.4 Assets (assets/)

Asset File Features & Functionalities
assets/css/style.css Central design system. Defines color tokens, responsive grid layouts, card designs, badges (badge-available, badge-issued, badge-overdue), modal dialogues, mobile hamburger menu animations, and media queries.
assets/js/slms-store.js Centralized Reactive State Engine. Automatically polls /api/* every 3.5s, keeps localStorage updated, handles CRUD operations, enforces 3-book limit and 14-day due date calculation, and dispatches slms_data_changed events.
assets/js/auth-session.js Session and RBAC manager. Updates navbar buttons based on logged-in role (Admin vs Student vs Guest), protects book borrowing behind student authentication, and injects the 3-line mobile hamburger menu.
assets/js/main-animations.js UI micro-animations: IntersectionObserver scroll-reveal, navbar elevation shadow on scroll, floating back-to-top button, animated number counters, and accordion FAQ toggles.

🔄 3. End-to-End User Workflows

Workflow 1: Public Discovery & Catalog Exploration (Guest Journey)

Visitors can search the full catalog, filter by subject category, and preview book details without logging in.

  1. Visitor navigates to http://localhost:3000.
  2. Home page loads and dynamically renders 6 featured catalog cards with real-time availability badges.
  3. Visitor clicks "Explore Full Catalog" and is routed to Pages/catalog.html.
  4. Visitor types keywords into the search box or clicks category buttons (Economics, Science, Technology, etc.).
  5. Catalog grid dynamically re-renders in real-time matching the filter criteria.
  6. Clicking a book opens the detail modal displaying cover, author, ISBN, stock, and synopsis.
